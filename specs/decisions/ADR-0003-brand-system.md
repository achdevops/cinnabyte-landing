# ADR-0003 — Sistema visual y logo transparente

- Estado: Aceptada
- Fecha: 2026-09-11

## Contexto

Cinnabyte necesita unir una identidad artesanal y digital sin saturar la interfaz ni hacerla parecer un producto SaaS. El logo nuevo incorpora roll, nombre y la línea `ROLLS · COFFEE · CODE · GOOD VIBES` sobre transparencia.

## Decisión

Centralizar la paleta en tokens CSS: Mint `#74D69C`, Pink `#FF3E86`, Cinnamon `#C66A32`, Espresso `#211713`, Cream `#FFF7EE` y White `#FFFFFF`. Usar Space Grotesk y mantener el logo maestro transparente, con derivados optimizados para web.

## Consecuencias

- White y Cream dominan la página; los colores intensos tienen funciones específicas.
- Pink se reserva para conversión, Mint para secundarios e información y Cinnamon para detalles artesanales.
- El logo necesita una superficie clara cuando se coloca sobre Espresso.
- Cambiar marca requiere actualizar tokens, logo web, favicon, flyer y pruebas visuales.

## Condiciones para revisarla

Revisar ante un rebranding formal, un sistema de empaques nuevo o la apertura del coffee shop físico con necesidades adicionales de señalética y carta.
